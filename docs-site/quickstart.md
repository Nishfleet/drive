# Quickstart

A Drive is a folder that works like any other folder. Your files live on our
storage, your Mac opens them on demand, and your agents read and write the same
files. Everything below is three steps and one command.

## Before you start

You need an account on a machine running macOS or Linux. The drive is not open
yet, so ask on the pricing page and we will send an invite.

## Three steps

### 1. Install

One command in your terminal. It puts the `drive` command on your machine and
nothing else.

```sh
curl -fsSL https://get.drive.dev | sh
```

### 2. Sign in

```sh
drive init
```

`drive init` opens your browser once. Approve the request there and come back
to the terminal. That is the whole sign-in.

### 3. Use it

A folder called **Drive** appears in your home directory. Open it in Finder,
save a file into it from any app, and it is on your Drive. Nothing else to
configure.

## What you get

- A folder every app on the machine can read and write.
- Files stream on demand: a 5 GB video opens without downloading first.
- Every agent tool already on the machine is connected to the same folder.
- The first $1 of storage every month is free, and no card is needed.
