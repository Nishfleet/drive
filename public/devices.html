Devices

Devices and agents that can use your drive. Turn any off with one click. To get events sent to your own server, see Webhooks.

Add a computer or an agent

A computer

  1. Install the command. One line for your system.
  2. Run drive login . It opens this site; press Approve.
  3. Run drive init . Your drive appears as a folder.

An agent

  1. On a computer that is already added, run drive init . It finds your agent tools.
  2. Or pick one yourself: drive agents connect claude .
  3. The agent gets its own folder and its own key. It shows in the list below, and Turn off stops it at once. What an agent key can do.
